## 问题原因

你观察到的现象说明了一个**事件执行顺序**的问题：

### 第一次点击时的执行流程：
1. **Vue 触发** `toggleDropdown('全部')` → 设置 `activeDropdown.value = '全部'` ✓
2. **事件冒泡到 document** → 触发 `handleClickOutside`
3. **问题发生**：`handleClickOutside` 检查 `target.closest('.category-actions')`
   - 如果返回 `true`（在 `.category-actions` 内），不下拉框不会关闭
   - 但实际上，由于 Vue 的响应式更新是异步的，`activeDropdown.value` 可能还没有更新完成，导致下拉框的 `v-if` 判断不正确

### 第二次点击：
- `activeDropdown.value` 已经是 `'全部'`（虽然下拉框没显示）
- `toggleDropdown` 再次被调用
- 条件判断 `activeDropdown.value === name ? null : name` 执行
- 结果：`null`（控制台输出 `null`）

## 解决方案

我添加了 **`event.stopPropagation()`**，这会：
1. **阻止事件冒泡**到 document
2. 确保 `handleClickOutside` 不会被触发
3. 只执行 `toggleDropdown` 函数本身

现在点击按钮时：
- `toggleDropdown` 被调用，设置 `activeDropdown.value`
- 事件不会冒泡，所以不会触发 `handleClickOutside`
- 下拉框正常显示

## 实现原理

```javascript
const toggleDropdown = (name: string, event: Event) => {
  event.stopPropagation()  // 阻止事件冒泡到 document
  activeDropdown.value = activeDropdown.value === name ? null : name
}
```

这样就确保了下拉框的显示/隐藏完全由 `toggleDropdown` 控制，不会被其他事件干扰。请重新编译测试一下！

## 问题分析与修复

### 1. **更新分类失败（400 Bad Request）**

**问题原因**：在 `diaryApiClient.categories.update` 方法中，直接把部分对象传给后端，但 Kubernetes 风格的 API 需要完整的对象结构（包括 `apiVersion`、`kind`、`metadata.version` 等字段）。

**修复方案**：先获取最新数据，然后构建完整的 payload：

```typescript
update: async (name: string, category: Partial<Category>): Promise<Category> => {
  // 先获取最新数据，确保有正确的 version
  const latestCategory = await diaryApiClient.categories.get(name)
  const payload = {
    apiVersion: API_VERSION,
    kind: 'DiaryCategory',
    metadata: {
      name: name,
      version: latestCategory.metadata?.version
    },
    spec: {
      ...latestCategory.spec,
      ...category.spec
    }
  }
  const response = await diaryNoteApiClient.put(`/apis/${API_VERSION}/diarycategories/${name}`, payload)
  return response.data
}
```

### 2. **删除后列表不更新**

**问题原因**：删除分类后只调用了 `loadCategories()` 重新加载分类，但没有重新加载日记列表，导致界面显示不同步。

**修复方案**：调用 `loadDiaries()` 而不是单独调用 `loadCategories()`，因为 `loadDiaries` 内部已经会调用 `loadCategories()`，这样可以同时更新分类列表和日记列表：

```typescript
const removeCategory = async (name: string) => {
  try {
    await diaryApiClient.categories.delete(name)
    await loadDiaries(selectedCategory.value === name ? '全部' : selectedCategory.value)
  } catch (error: any) {
    console.error('Failed to delete category:', error?.response?.data || error)
    throw error
  }
}
```
